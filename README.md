# Hsin — ChatGPT Work Pet

An animated fox spirit companion inspired by the supplied Hsin reference art. This repository contains **only the current Hsin pet**.

![Hsin waving](hsin-waving.gif)

## Add Hsin to your ChatGPT Pets

1. Open the [Hsin adoption link](https://chatgpt.com/s/sharepet_6abc1465705881919dd246f8725ce8b5) while signed in to ChatGPT.
2. Choose **Adopt** to add your own copy to your Pets library.
3. Open Pets in ChatGPT Work and select **Hsin** as your active companion.

The share link is the easiest way to install Hsin. GitHub alone does not automatically add a pet to ChatGPT.

## Files

- [hsin-pet-spritesheet.png](hsin-pet-spritesheet.png) — transparent v2 sprite sheet (1536 × 2288, 8 columns × 11 rows).
- [hsin-contact-sheet.png](hsin-contact-sheet.png) — all poses and look directions.
- [hsin-waving.gif](hsin-waving.gif) and [hsin-jumping.gif](hsin-jumping.gif) — animation previews.

## Create from the sprite sheet manually

If you prefer to create your own custom copy instead of using the adoption link, download `hsin-pet-spritesheet.png` and use a ChatGPT Work session with the Pets plugin. Ask it to validate the file, create a pet named Hsin from it, and select the new pet. The sheet uses the Pets v2 layout.

This repository does not include the reference images or earlier character drafts.
